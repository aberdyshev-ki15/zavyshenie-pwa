# Калькулятор завышения (PWA для iPhone)

Автономная версия исходного HTML-калькулятора с иконкой для iPhone.

## Публикация

1. Загрузите содержимое этого архива в корень отдельного репозитория GitHub.
2. В Settings → Pages выберите Deploy from a branch, main, / (root), Save.
3. Откройте публичный адрес GitHub Pages через Safari на iPhone.
4. Выберите Поделиться → На экран «Домой» → Добавить.

При первом запуске нужен интернет. После загрузки приложение может работать
без сети, кроме сторонних ссылок и веб-шрифтов.

Расчёты и законодательные сведения перенесены из исходного HTML без
независимой юридической проверки актуальности.
